---
title: Rolling deploy
description: Safe apply flow with explicit confirmation and rollback window.
---

## Goal

Apply config updates without direct fallback.

## Steps

1. Prepare config and validate.
2. Run `hubctl verify --config ...`.
3. Start deploy preview.
4. Confirm with timeout: `hubctl deploy --confirm-within 5m`.

## Evidence

Capture status and revision before and after deployment.
