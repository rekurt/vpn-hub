```yaml
  - id: rotating-edge
    type: xray
    role: egress
    source:
      kind: subscription
      value: ENC[AES256_GCM,data:SYNTHETIC,...]
```

A refresh accepts at most 32 usable VLESS candidates and 8192 bytes per line, runs within a two-minute default deadline, rejects special-use/internal destinations, proves candidates in isolation, and promotes only a working one. The last-known-good link remains restorable.

The `ENC[...]` fragment is illustrative, not a complete SOPS document. Use `sops` to produce the real envelope; never hand-author it.
