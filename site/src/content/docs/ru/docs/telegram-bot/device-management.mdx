---
title: Device management by bot
description: Add, issue, reissue, and revoke devices from Telegram.
---

Use these screens:

- Device list
- Device card
- Profile send/reissue
- Revoke

## Runbook

1. Open the device list.
2. Open the target device card.
3. Issue reconfigure command.
4. Confirm success message and store revision from status.

If a device profile was leaked, rotate hub keys through hub settings and re-issue required devices.
