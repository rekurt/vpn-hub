## Files

- `/etc/vpn-hub/hub.yaml`
- `/etc/vpn-hub/devices.yaml`
- `/etc/vpn-hub/tunnels/`
- `/var/lib/vpn-hub/`

## Commands

- `hubctl deploy`
- `hubctl validate`
- `hubctl status`

All production installs should keep binaries in `/usr/local/bin` and systemd units under `/etc/systemd/system`.
