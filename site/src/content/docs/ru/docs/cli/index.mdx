VPN Hub is operated through `hubctl`, `vpn-hub-agent`, and `vpn-hub-bot` binaries.

- `hubctl`: declarative config, tunnels, devices, health, and deployment lifecycle.
- `vpn-hub-agent`: background reconciler and runtime observer.
- `vpn-hub-bot`: Telegram control plane for operators with constrained privileges.

Each command set is documented in source tests and docs examples in this section.
