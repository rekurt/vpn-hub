<ConfigField path="tunnels[].health.https_url" type="HTTPS URL string" required="No" defaultValue="Empty" validation="Must use https, include a safe hostname, and contain no whitespace." secret="Do not put credentials or tokens in probe URLs." sideEffects="Fetches the URL through the tunnel." example="https://example.com/health" />

<ConfigField path="tunnels[].health.dns_name" type="hostname or IP string" required="No" defaultValue="Empty" validation="At most 253 characters with safe host-label syntax; leading dashes are rejected." secret="No." sideEffects="Resolves the name through the tunnel's DNS context." example="example.com" />

```bash
sudo hubctl --config /etc/vpn-hub test tunnel office
```

No configured probe means `unknown` and a non-zero exit, never an inferred healthy status.
